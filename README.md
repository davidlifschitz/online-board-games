## Goals

Each prompt is designed around the same general principles:

- Open-source implementation
- Deployable on Vercel
- Mobile-friendly browser UI
- Computer opponents where appropriate
- Online multiplayer where appropriate
- Deterministic, testable game engines
- Original or appropriately licensed artwork and assets rather than copying proprietary visual designs
