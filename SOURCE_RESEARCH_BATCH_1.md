# OS Online Board Games — Source Research, Batch 1

All five Batch 1 games are original implementations. The repositories below were used only as permissively licensed mechanics, regression, AI, or browser-UX references. No upstream source code, artwork, text, or assets were copied into these games.

| Concept | Candidate | License verified from repository | Implementation | Use | Result |
|---|---|---|---|---|---|
| Dots and Boxes | `aqeelanwar/Dots-and-Boxes` | MIT | Python | Board legality, scoring, AI/game-loop reference | audited |
| Dots and Boxes | `rolyatmax/dots` | MIT | JavaScript | Browser/canvas interaction reference | audited |
| Mancala / Kalah | `josephsivits/mancala-js` | MIT | JavaScript | Kalah turn/rule regression | audited |
| Mancala / Kalah | `OguzhanUmutlu/webmancala` | MIT | TypeScript | Web Mancala interaction reference; different ruleset | audited |
| Mastermind-style | `nuragic/MastermindJS` | MIT | JavaScript / React | Feedback/game-loop reference | audited |
| Mastermind-style | `geobalas/colorbreaker` | MIT | browser app | Compact browser feedback reference | audited |
| Farkle | `Varrus/JMFarkle` | MIT | browser app | Roll/keep/bank reference | audited |
| Farkle | `opub/farkle` | MIT | JavaScript | Scoring/gameplay regression reference | audited |
| 2048 variants | `gabrielecirulli/2048` | MIT | JavaScript | Canonical slide/merge ordering | audited |
| 2048 variants | `mateuszsokola/2048-in-react` | MIT | TypeScript / Next.js | Modern browser interaction reference | audited |

Excluded candidates without an explicit license were not used as code/data/art sources.
