High Table

An original browser interpretation of the traditional President-family climbing game: match the group size, climb the rank, pass strategically, and empty your hand first.

Core play uses equal-rank groups. A played group must match the current group size and beat its rank. Four-of-a-kind can reverse rank order.

Rules & provenance

High Table uses original branding, CSS card faces and an independently written rules engine. MIT President implementations were checked as MCTS/game-flow references only.
