# Charades / Heads-Up-style party game

Build an original open-source phone-first guessing game designed for in-person groups and optional remote play.

## Core gameplay
- One player holds or views the device while teammates give clues or act out the displayed prompt.
- Swipe/tap correct, pass, or undo.
- Fixed-length rounds with score summary.
- Rotate players/teams across rounds.

## Modes
- Charades: acting only.
- Verbal clues with configurable forbidden-word rules.
- Team battle.
- Remote mode where clue-givers see the prompt and guesser does not.

## Content
- Original/open prompt decks: movies, objects, actions, places, kid-friendly, custom user decks.

## Mobile features
- Very large typography.
- Optional device-tilt gestures when browser sensor permissions allow, with touch controls always available.
- Sound/haptic cues where supported.

## Engineering
- Seedable decks, no-repeat logic, custom deck import/export, round history.
- Tests for scoring, deck exhaustion, rotation, timer, and hidden prompt visibility.
- Open-source license, README, Vercel/PWA deployment.
