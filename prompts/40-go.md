# Go

Build an open-source browser Go platform with legal-rule enforcement, analysis tools, and online play.

## Rules
- Support 9x9, 13x13, and 19x19 boards.
- Implement liberties, captures, suicide according to selected ruleset, ko/superko policy, pass, resignation, handicap stones, komi, and scoring.
- Clearly select/document one default ruleset such as Tromp-Taylor, Chinese, or Japanese; do not mix scoring rules silently.

## Modes
- Local 1v1.
- Online rooms with clocks.
- Vs computer if a suitable open-source WebAssembly/local engine is practical; otherwise provide rule-based beginner bot and analysis hooks.
- SGF import/export and replay.

## UI/engineering
- Board coordinates, last-move marker, captured counts, territory/scoring review, dead-stone agreement flow.
- Efficient group/liberty tracking and board hashing for ko.
- Tests for capture, multi-group merges, ko, suicide, pass termination, handicap, and scoring under the selected ruleset.
- Open-source assets/dependencies, README, license, Vercel deployment.
